TECHNOVA SOLUTIONS WEBSITE
===========================

Pages:
- index.html     Company home page
- about.html     Detailed company information
- test.html      15-question test
- register.html  Registration + email submission
- certificate.html Confirmation page
- style.css      Responsive styling

IMPORTANT EMAIL SETUP
---------------------
1. Open register.html in a text editor.
2. Find:
   https://formsubmit.co/YOUR_EMAIL@example.com
3. Replace YOUR_EMAIL@example.com with the email address that should receive registrations.
   Example:
   https://formsubmit.co/yourname@gmail.com
4. Upload the updated files to GitHub Pages.
5. The first submission may require the receiving email to confirm/activate FormSubmit.
6. After activation, new registration submissions are forwarded to that email.

GITHUB PAGES
------------
Create a repository, upload all files in this folder to the repository root,
then enable Settings > Pages > Deploy from branch > main > /(root).

NOTE
----
This is a static website. Certificate creation itself is represented by a confirmation
page; it does not generate a PDF certificate automatically.
